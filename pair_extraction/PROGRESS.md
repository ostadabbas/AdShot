## Test suite (persistent) — `pair_extraction/tests/`
Replaces the old throwaway scratchpad scripts. One script per step + a runner.
- Run: `TORCH_HOME=… $PY tests/run_tests.py [--quick|--steps 0,6,7|--list]`.
- `--quick` skips heavy (GPU/model/video/full-dataset) tests; SKIP = stage not built / input missing (not a failure).
- Strategy = **exact + tolerant mix**; each stage fed the *reference inputs* of the prior stage so float drift doesn't compound (except step 5 = true e2e).
- Backfill 0–4 done; forward 5–8 encode the comparison + a **contract** the future code must satisfy:
  - Step 7: `s3_pairing.run_pairing(shotsplits_dir=None, clusters_dir=None, data_csvs=None, out_path=None)` (defaults to config when None).
  - Step 8: `run_pipeline.py --stage {all,processing,clustering,pairing}`; optional `build_parser()` so the test can assert threshold default == config (0.1).
- Clustering(6)/pairing(7) tests need **no GPU/video** (run vs full reference artifacts). Heavy Stage-1 tests target only ad `XEEvoOwsqEY` (the one with a local video; brand folder is `Aqua Living Factory Outlets`, no `975 ` prefix).
